# HardcoreCompass

A modular Paper/Purpur 1.21.1 plugin targeting Java 21. HardcoreCompass tracks lives by player UUID, issues a lodestone compass on first join, and on death consumes a life, clears player state, and asynchronously relocates survivors to a safe surface in a configurable radius. The last-life death is handled without issuing a compass. Configuration supports friendly English/Spanish messages and starter item options.

## Current status

Initial repository setup. Source, build configuration, tests, and usage documentation are being added next. Verified target server: Purpur 1.21.1; Java 21.
